# 2026-10-18 SEO 修正

- 新增 `src/pages/404.astro`，產生根目錄 `404.html`，讓 Cloudflare Pages 停用預設 SPA 回退。未知網址應回傳 HTTP 404；錯誤頁含日文與中文導覽並設定 noindex，不指向首頁 canonical。
- 收藏屬於瀏覽器本機內容，兩語版皆設定 noindex。正式商品、分類與文章維持可索引；預覽版維持全站 noindex。
- 共用版型補充 Open Graph、WebPage 與首頁 WebSite；商品／分類補上與可見連結一致的 BreadcrumbList。歷史觀測價不輸出商店 Offer。
- 月報最新一期入口的 hreflang 改指向固定期號網址，與 canonical 一致。

驗證：`node --test tests/*.test.js`（55 項）、`python3 tools/check_categories.py`、`npm run build`，再執行 `node tools/check_seo.mjs`。後者檢查全部建置 HTML 的 metadata、JSON-LD、canonical 語言互連、收藏 noindex 與根目錄 404。預覽建置可執行 `node tools/check_seo.mjs dist --preview`。

另需在 Cloudflare 分支預覽與正式站確認未知路徑的 HTTP 狀態，不以本機存在 404.html 代替正式驗證。價格、查核狀態、來源證據、GA 與 GSC 驗證碼均保留。

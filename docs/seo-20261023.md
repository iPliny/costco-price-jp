# 2026-10-23 SEO 更新日期修正

門市新紀錄頁原本和線上新紀錄頁共用全站日期，現在分別取畫面同一組 `recentProducts` 資料的最新觀測日。本次建置：門市 2026-10-19，線上 2026-10-22。

週報與列表的 sitemap 增加來源日期：各篇用 updated 或 date，列表取最新一篇的修改／發布日；沒有文章時省略。文章日期必須是有效的日曆日期，修改日不得早於發布日。週報 JSON-LD 改用共用序列化函式，摘要裡的文字不能提前結束 script 元素。
